# Pratik Janrao & Associates

A modern, editorial website for Pratik Janrao & Associates, Chartered Accountants in Pune.

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

All production image assets are included in `public/images`.
